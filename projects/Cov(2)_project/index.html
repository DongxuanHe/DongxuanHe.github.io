Overview

This project studies the Frank-Wolfe algorithm for smooth convex optimization over compact convex sets, with a focus on its worst-case performance and the design of improved fixed-step variants.

Starting from the standard constrained problem [ \min_{x \in C} f(x), ] where (f) is convex and smooth and (C) is compact and convex, the project first analyzes a modified Frank-Wolfe method with a recursively defined step-size sequence. The analysis establishes a convergence bound of the form [ f(x_N) - f(x^\star) \leq \delta_N. ]

The main goal is then to determine whether this bound is tight, by characterizing the true worst-case value after (N) iterations.

Main Ideas

To study worst-case behavior, this project reformulates the analysis problem into an optimization problem over all smooth convex functions and feasible iterates generated by Frank-Wolfe. Using interpolation conditions and the Performance Estimation Problem (PEP) framework, the worst-case analysis can be converted into a semidefinite program (SDP).

This makes it possible to:

  • compute the exact worst-case objective gap after a finite number of iterations,
  • compare the SDP value with the analytical upper bound,
  • and investigate whether the standard Frank-Wolfe proof is tight.

Generalized and Fixed-Step Frank-Wolfe Methods

Beyond the standard algorithm, this project also considers a more general family of Frank-Wolfe-type methods in which:

  • the linear minimization direction can depend on previous gradients and iterates,
  • the next iterate is chosen as a convex combination of previously queried points,
  • and the full method can be parameterized by structured coefficient matrices.

This formulation leads to a broader fixed-step Frank-Wolfe family, which enables systematic search for improved algorithms within a constrained class of methods.

Key Topics

  • Frank-Wolfe algorithm for smooth convex optimization
  • Worst-case convergence analysis
  • Performance Estimation Problems (PEP)
  • Semidefinite programming (SDP) reformulations
  • Fixed-step first-order method design
  • Interpolation-based analysis of optimization algorithms

Future Work

Possible next steps include:

  • solving the derived SDP numerically to test tightness of the standard bound,
  • comparing different fixed-step coefficient choices,
  • and searching for optimal Frank-Wolfe-type algorithms within the generalized family.
