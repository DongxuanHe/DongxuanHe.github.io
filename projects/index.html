Research Projects

Curriculum Learning for Multi-Agent RL

Selecting training tasks to accelerate learning on a target multi-agent task
Project page ↗
Overview: Curriculum Learning for Multi-Agent RL

This ongoing project studies how to select intermediate training tasks that help a multi-agent policy learn a target task. Simulated combat tasks vary in allied and opposing team sizes. Task selection considers transfer difficulty and estimated gains on the target task, with current work exploring gradient information and task features as guidance for curriculum design.

Convex Optimization: Frank-Wolfe Methods and Worst-Case Analysis

Performance estimation and SDP-based analysis for convex optimization algorithms
Project page ↗
Overview: Convex Optimization: Frank-Wolfe Methods and Worst-Case Analysis

This project studies the worst-case performance of Frank-Wolfe methods for smooth convex optimization and the design of fixed-step variants. Using interpolation conditions and the Performance Estimation Problem framework, it formulates semidefinite programs to investigate convergence bounds and their tightness. Ongoing work examines numerical verification and the search for improved methods within a parameterized algorithm family.

Multi-Robot Cooperative Pushing

Learning to push and align objects with two robots using limited egocentric observations
Project page ↗
Overview: Multi-Robot Cooperative Pushing

This ongoing project extends EgoPush to two mobile robots that must move and align a rectangular object using limited egocentric observations, without explicit inter-robot communication. Policies are trained with parameter-shared MAPPO under centralized training and decentralized execution. Current work evaluates target-pose alignment in simulation and examines unsuccessful rollouts to understand coordination failures.

Grid Expansion and Data-Center Interconnection

Planning grid upgrades and phased data-center admissions under network and investment constraints
Project page ↗
Overview: Grid Expansion and Data-Center Interconnection

This project studies how grid upgrades and phased data-center connections can be planned together over multiple years. A mixed-integer model jointly schedules upgrades and annual load admissions under DC power-flow constraints, investment budgets, and construction lead times. Current studies use Virginia data-center records and a synthetic transmission network to examine the effects of connection locations and power-import limits.

Course Projects

Reinforcement Learning for UAV Obstacle Avoidance

Learning a reactive UAV controller in a 2D partially observable environment with randomized obstacle layouts
Project page ↗
Overview: Reinforcement Learning for UAV Obstacle Avoidance

This course project trains a PPO policy to navigate a UAV from start to goal while avoiding static obstacles in a lightweight 2D simulation. The policy uses local range sensing and goal-relative information rather than a global map. Randomized layouts support evaluation on unseen environments, with an Artificial Potential Field controller as a baseline. Evaluation considers success, collisions, path length, energy, and control smoothness.

Active Learning Strategies for Image Classification

A controlled empirical study of active learning sampling strategies on Fashion-MNIST, with a focused analysis of BALD.
Project page ↗
Overview: Active Learning Strategies for Image Classification

This course project compares pool-based active learning strategies on Fashion-MNIST using a shared classifier, labeling budget, and training protocol. Methods include BALD, BADGE, CSAL, uncertainty sampling, and Core-Set selection, with random sampling as a baseline. The focused BALD analysis examines how uncertainty estimates evolve as labeled data accumulate and how label efficiency trades off against computational cost.
